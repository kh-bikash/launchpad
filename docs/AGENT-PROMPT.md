# Coding-agent prompt

Use this prompt after connecting the Autosana MCP server:

```text
Test the launch-plan feature locally using Autosana.

Create a launch checklist, enter "Autosana agent demo" as the project
name, keep all workstreams selected, and select Review launch plan.
Verify that the Ready for review screen appears.

Run the same flow on a small mobile device or viewport. Check that the
primary action is fully visible and that its purpose is clear.

Read the functional and UI/UX findings, fix the application code, and
rerun the complete flow until it passes.
```

Do not disclose or commit the Autosana API key.
